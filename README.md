# Logbuch der Lok

Spielleiter-App für eine Blitzbahn-Kampagne in Khorvaire: Charakterbögen, Initiative-Tracker, Notizen, Regelbibliothek mit Volltextsuche und eine Leinwand-Ansicht für den großen Bildschirm.

**App öffnen und installieren:** https://mrbrainfog.github.io/logbuch-der-lok/

- Läuft nach dem ersten Öffnen auch ohne Internet.
- Alle Kampagnendaten und PDFs bleiben auf dem eigenen Rechner. Im Repository liegt nur der Programmcode.
- Neue Versionen lädt die installierte App beim nächsten Start mit Internet automatisch.

Der Ordner `quelle/` enthält die Quelldatei und das Build-Skript. Die Dateien im Hauptordner werden daraus erzeugt.

PDF-Darstellung: [pdf.js](https://github.com/mozilla/pdf.js) von Mozilla (Apache-2.0).
